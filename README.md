# CryptoGram

CryptoGram is a simple project that combines **FastAPI**, **Flask**, and **Matplotlib** to perform basic cryptographic operations and generate visual plots.

---

## 🚀 Features
- Cryptographic text transformations  
- FastAPI backend for API processing  
- Flask frontend for user interaction  
- Matplotlib-based plot generation
